---
name: memory-save
description: 把当前会话的一个决策/坑/进度写进 .memsearch/memory 并增量建索引。参数 = 要记的内容（可为空，为空时从最近对话总结）。
---

把"事件记忆"落盘。**只记事件与决策，不抄工程文档。**

执行步骤：

1. **查重**（必须先做）：
   ```bash
   memsearch search "<主题关键词>" -k 3
   ```
   命中同主题旧段落 → 修订那一段（保持日期原样，补一条"更新于"），不要新建重复段落。
2. 确定目标文件：`.memsearch/memory/<今天>.md`（今天 = 系统日期，格式 `YYYY-MM-DD`）。文件不存在就创建，存在则追加。
3. 追加格式：
   ```markdown
   ## <YYYY-MM-DD> <一句话标题>

   - 决定/事实：
   - 理由：
   - 代价或风险：
   - 验证方式（跑了什么命令、看到什么输出）：
   - 指针：见 `路径#小节`（涉及工程细节时必填，不要复制正文）
   ```
4. 增量索引并报告结果：
   ```bash
   memsearch index .memsearch/memory
   ```
   把输出的 `Indexed N chunks.` 报给用户。
5. 若本次是**修正**了旧记忆（旧结论错了），在第 1 步命中的旧段落顶部加一行 `> 已过时（<日期>）：<原因>，见下方新记录。`，**不要直接删除历史**。

禁止：写入密钥/token/内网地址；写入纯代码片段；一次性写超过 3 条。
