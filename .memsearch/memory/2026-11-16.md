## 2026-11-16 保存模型报 HTTP 502 = 后端没启动，不是模型故障

- 事实：浏览器开发时保存模型配置报「请求失败 HTTP 502」。根因是 Python 后端没在运行：Vite 代理在上游不可达时返回 **text/plain 的 502**（`vite/dist/node/node.js:19867`），前端把它当成模型错误显示。同时 `desktop/.env` 缺失，即使后端在跑也会 401。
- 理由：502/504/网络失败语义是「请求没到后端」，必须与「模型拒绝请求」区分开；否则会把本地环境问题误判成密钥/额度问题，浪费排查时间。
- 代价或风险：需要维护一条前端错误映射 + 一个离线横幅；浏览器开发从此依赖两个进程（后端 + Vite）。
- 验证：起 `scripts\dev.ps1`（后端 8765 + Vite 1420）→ 经 `http://127.0.0.1:1420/api/model-configs` 实测 `POST` 返回 201、`GET` 返回列表；`desktop` 单测新增 4 条覆盖 502/503/504 与 ApiError 分类。
- 指针：见 `ai-novel-studio/KnowledgeBase/INDEX.md#常见故障`、`ai-novel-studio/scripts/dev.ps1`
