# 技术债

> 一条债一行，只引用 `T-xx`。修法在 [`TaskRegister.md`](TaskRegister.md) 里，本页不复述。

## 高：会让功能"看着有、其实空"

| 债 | 任务 | 影响面 |
|---|---|---|
| 摘要只读不写，"前情提要"永远为空 | `T-01` | 长文连贯性，AI 写长篇小说等于没有记忆 |
| AI 产出记成 `user` 快照，血缘丢失 | `T-02` | 无法回答"这段是谁写的"、无法回滚 AI 批次 |
| `outlines` 是死表 | `T-04` | 大纲功能无法持久化，等于一次性提示词 |
| `agent_configs` 是死表 | `T-07` | 无法按 Agent 分配强弱模型，成本与质量都不可调 |

## 中：正确性有隐患但当前不炸

| 债 | 任务 | 影响面 |
|---|---|---|
| 降级链与 PromptService 零测试 | `T-05` `T-06` | 主模型限流时可能整批失败，且改模板无回归网 |
| 结构化输出缺失，只能吃自由文本 | `T-03` | 所有"回写结构化数据"的需求都会卡在这里 |
| 生成记录只存 `prompt_key` | `T-14` | 改模板后历史结果不可复现，评测无从谈起 |
| 上下文只靠章节截断 | `T-12` | token 要么浪费要么超窗 |
